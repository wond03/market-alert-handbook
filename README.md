# 交易信号系统说明

这个仓库只放说明文档，不放程序代码。程序代码在另一个仓库里。

## 这套系统做什么

系统盯着比特币和黄金两个品种的行情，用一套结构交易的规则判断什么时候可能出现入场机会。判断成立后，它做两件事：

1. 把信号发到电报机器人，内容包括方向、入区、入场参考价、止损参考价、止盈参考价。
2. 在交易所模拟盘自动开一笔小仓位，保证金五美元，杠杆一百倍，逐仓模式。止损和止盈不下单，由人结合实际行情手动设置。

## 文档目录

- 业务框架：系统由哪些部分组成，数据怎么走，什么时候运行。
- 信号逻辑与参数：信号怎么判定，每个数字是什么意思，为什么这样定。

## 一句话提醒

这套规则目前只是把历史规律写成固定条件。历史回测在修正成交假设后是亏损的，所以现在用小仓位实盘和模拟盘累计样本，验证它到底有没有优势。任何信号都不构成投资建议。
